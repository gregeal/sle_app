# P5 delivery: weekly teacher and consolidated repairs

Approved scope: complete P5, including Today integration and weekly reporting.
User choices: four-skill placement; five selectable weekdays (Monday–Friday by
default); recommended starting lesson using existing work; progression with an
explicit override; 20 live teacher connection minutes per study week.

## Implemented behavior

- Schema v9 adds weekly class state, typed evidence, frozen feedback jobs and
  transactional voice leases. Existing course/SRS/history remains in place.
  Legacy weekly completion without valid evidence stays historical/unverified.
- A shared validator rejects unknown track/lesson bindings, invalid assignment
  modes/IDs/days, daily budget errors and all skill-share violations. The allocator
  selects a feasible five-minute allocation deterministically; 3×30 is rejected.
- Placement uses editable VoiceDraft with the existing device/cloud choice,
  microphone lifecycle cleanup and selection-navigation guard. It saves drafts,
  adds eight original reading/listening questions, marks assisted listening, and
  offers a no-AI provisional route and explicit track/lesson confirmation.
- Classes persist stage, quiz answers, results, skips and practice references.
  Incorrect answers are formative; unattempted steps require an explicit skip.
- Live practice saves transcript evidence before separate feedback. Long feedback
  uses bounded chunks and reuses successful results. Manual conversation reuses
  the existing speaking partner and mistake-review system. Offline solo work
  requires an explicit confirmation/reflection.
- Realtime waits for the server's effective teacher/manual-turn configuration
  before presenting the session as connected. Failed configuration is actionable.
- Weekly assignments drive Accueil and Classe from the same records. No legacy
  obligations appear on weekly rest days. Selected dates are frozen per cycle;
  pause/resume shifts remaining dates. Catch-up swaps one same-skill/equal-duration
  block rather than adding work. Week closure is local/offline.
- Closed weeks retain an evidence snapshot. Optional reports use strict bounded
  JSON, source-ID validation, explicit unknown skills and a single malformed-output
  retry. Failed jobs require explicit retry. Only the newest closed week receives
  an automatic report on a later online visit, with an opt-out in Classe.
- Progression explains repeat/advance recommendations and records overrides.
  The next-week dialog offers both tracks and all lessons, including explicit
  revision/transition at the end of a track. Missing feedback does not block choice.
- Progrès separates planned, credited and observed time. Conversation duration is
  not learner airtime or a language-quality measure. Weekly verified completions
  contribute once to streaks and credited totals.
- Five navigation destinations remain; Paramètres is the Accueil gear action.

## Migration and failure policy

The v1/v7/v8 fixtures represent their actual older schema, not a newer schema with
only user_version changed. Existing malformed weeks can be archived through a
recovery action while other learning history is preserved. Closed-week evidence
cannot be rewritten by delayed completions. Valid repeated productions are retained
without crediting an assignment twice; duplicate saves remain idempotent.

Voice allowance is local to this app/browser, alongside existing server/provider
cost controls. An unsettled reservation is conservatively charged after a crash;
it does not reset on reconnect. It is not cross-device synchronization or a promise
of exact provider billing. Cloud dictation remains a separate opt-in service.

Teaching/listening text and drafts work offline. TTS requires an installed French
voice; device dictation may require internet. Assisted listening and solo reflection
remain distinct from demonstrated independent comprehension/production. Report
levels are unofficial and pronunciation/fluency cannot be established from text.
